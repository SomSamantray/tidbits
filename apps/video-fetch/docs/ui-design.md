# UI design — nerdy caricature system

- **Palette:** cream paper background, ink borders, terminal-green accents (`#00ff9c`), pastel chips for status.
- **Typography:** rounded display font + monospace labels for technical fields (`audio_mode`, `quality_cap`).
- **Mascot:** one wizard emoji block per screen — idle, loading, success, error. No competing illustrations.
- **Controls:** chunky `2px` borders, offset shadows, large tap targets for mobile.
- **Complexity:** primary flow stays one screen; advanced options live in future "Nerd knobs" accordion.

Inspired by cartoon design system discipline: mascots secondary to CTAs, max one character moment per view.
